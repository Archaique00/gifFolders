# GifFolders

Local Vencord userplugin that adds folders to the native GIF favorites picker.

## English

- Organizes favorite GIFs into local folders.
- Filters favorites with `All`, `Unsorted`, or a folder.
- Exports and imports the configuration as JSON.
- Uses English by default.
- Switches to French when the Discord/browser locale starts with `fr`.

## Francais

- Range les GIF favoris dans des dossiers locaux.
- Filtre les favoris avec `Tous`, `Non ranges` ou un dossier.
- Exporte et importe la configuration en JSON.
- Utilise l'anglais par defaut.
- Passe en francais quand la langue Discord/navigateur commence par `fr`.
